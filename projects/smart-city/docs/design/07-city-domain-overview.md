# 城市业务域总览

智慧城市不只是道路与传感器，而是把**城市生活相关信息**放进同一张可视化底图：停车、物业、小区、购物、吃喝玩乐、打卡点、排行榜等，都能在地图上被看见，再按需展开数据。

## 业务分层

```
城市底图（区 / 街道 / 小区 / 商圈）
    ├── 出行层：交通、停车
    ├── 居住层：小区、物业、设施
    ├── 消费层：购物、餐饮、娱乐
    ├── 互动层：打卡点、足迹、评论
    └── 运营层：排行榜、热度、活动
```

## 模块地图（现有 + 规划）

| 业务域 | 模块 | 状态 | 核心对象 |
|--------|------|------|----------|
| 交通 | `smartcity-traffic` | 已有 | 信号灯、路段、摄像头 |
| 停车 | `smartcity-parking` | 已有，待深化 | 停车场、车位、收费 |
| 餐饮 / 吃喝 | `smartcity-food` | 已有，待深化 | 门店、菜品、排队、榜单 |
| 购物 | `smartcity-shopping` | 已有，待深化 | 商场、店铺、客流、榜单 |
| 能源 | `smartcity-energy` | 已有 | 变电站、充电桩 |
| 环境 | `smartcity-environment` | 已有 | 空气、水位、噪声 |
| 小区 | `smartcity-community` | **规划** | 小区、楼栋、出入口 |
| 物业 | `smartcity-property` | **规划** | 工单、报修、公告、设施 |
| 玩乐 | `smartcity-leisure` | **规划** | 景点、场馆、夜生活点 |
| 打卡 / POI | `smartcity-checkin` | **规划** | 打卡点、足迹、徽章 |
| 排行榜 | `smartcity-ranking` | **规划** | 美食榜、购物榜、打卡榜 |

> 规划模块可按同一微服务模板扩展，不必改动无关业务服务。详见 [06-spring-cloud-microservices.md](./06-spring-cloud-microservices.md)。

## 信息在城市中如何呈现

1. **先可视化**：小区边界、停车场、门店、打卡点显示在城市场景上。
2. **再看数据**：点击对象看到占用率、排队、评分、热度、近期事件。
3. **再做互动**：用户可打卡、收藏、点赞；运营侧配置榜单与活动点。

## 角色

| 角色 | 关注点 |
|------|--------|
| 城市运营者 | 全局热力、异常、设施健康 |
| 物业人员 | 小区工单、设施巡检、公告 |
| 商户 | 门店客流、榜单位次、活动 |
| 市民 / 游客 | 停车、美食、购物、打卡、玩乐推荐 |

## 统一空间对象

所有城市事物尽量落到同一套空间模型：

| 字段 | 说明 |
|------|------|
| `id` | 全局唯一 |
| `module` | 所属业务模块 |
| `name` | 展示名称 |
| `category` | 细分类（如火锅 / 商场 / 地下车库） |
| `x` / `y` 或经纬度 | 可视化坐标 |
| `districtId` / `communityId` | 所属片区 / 小区 |
| `status` | online / warning / critical / offline |
| `tags` | 标签（亲子、夜宵、免费停车等） |
