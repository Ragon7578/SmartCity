# 项目管理文档

本目录由项目经理维护，面向干系人、协作 Agent 与研发同学。

技术愿景与领域设计见 [`../design/`](../design/)。

## 协作约定

- **产品品牌**：Urban Lens / 城景（平台）
- **运营叙事**：指挥城市
- **内容**：种子模块验证平台；候选模块或外部系统按契约接入
- 设计细节变更同步 `docs/design/`；周期与优先级变更同步本目录
